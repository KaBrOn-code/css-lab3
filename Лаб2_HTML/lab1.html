Owen Logic

среда программирования реле ОВЕН

О программе

Owen Logic — это среда программирования, которая нужна для создания алгоритмов работы программируемых реле, например приборов ПР100, ПР200 и панели ИПП120 производства компании ОВЕН.

В Owen Logic можно составить свою программу автоматизации и записать её в энергонезависимую память прибора. Программа рисуется на графическом языке FBD стандарта МЭК 61131-3.

Группы приборов

Приборы первого поколения — ПР100, ПР102, ПР200 и панели ИПП120.
Приборы второго поколения — ПР103, ПР205, ПР225, ОВК-П.

Важно: часть функций для приборов второго поколения недоступна для приборов первого поколения.

Логический сигнал

Логический сигнал принимает только два значения: включено (лог. 1) и отключено (лог. 0). Блок «И» с входами x1 и x2 выдаёт 1, только если оба входа равны 1. Для n входов всего 2n комбинаций.

Проект сохраняется в файл .owl, а резервная копия — в файл .owle. Сохранить проект можно клавишами Ctrl + S. После записи в прибор программа пишет Запись выполнена успешно.

Пример на языке ST

FUNCTION_BLOCK AND_BLOCK
VAR_INPUT
    x1 : BOOL;
    x2 : BOOL;
END_VAR
VAR_OUTPUT
    y : BOOL;
END_VAR
    y := x1 AND x2;
END_FUNCTION_BLOCK
